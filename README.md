## 📌 Project Overview

This project performs an exploratory analysis of clinical data from HCV patients using **pure MySQL**.

The analysis focuses on understanding relationships between patient demographics, fibrosis stage, histological grading, clinical symptoms, laboratory measurements, viral load, and treatment response.

The project is presented as a **Jupyter Notebook (`.ipynb`) containing SQL queries and their results**, making the analysis reproducible and easy to follow.

---

## 🎯 Objectives

The main objectives of this project are to:

- Explore the structure and characteristics of the HCV dataset.
- Analyze patient demographics.
- Examine fibrosis and histological staging.
- Investigate clinical symptoms across fibrosis stages.
- Analyze baseline laboratory measurements.
- Explore baseline and follow-up viral load.
- Measure changes in viral load during treatment.
- Classify patients according to treatment response.
- Investigate relationships between fibrosis stage and treatment response.
- Analyze baseline viral load using quartiles and percentiles.
- Demonstrate advanced SQL techniques using real clinical data.
